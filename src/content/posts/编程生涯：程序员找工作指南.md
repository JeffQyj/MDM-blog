## 一、为什么找工作

废话，当然就是为了钱。

不工作就没钱，没钱就活不下去。这个道理朴素到不需要任何解释。我们这一代人，从小被教育"要有理想""要追求热爱"，但等真正踏入社会才发现——**先解决生存问题，才有资格谈理想**。

我不想在这篇文章上升到什么薪资、单休、分配等社会问题，因为谈论这些没有任何作用。普通人只能保证自己活着，其他说啥也没用，说白了，就是没招了。那么与其抱怨环境，不如务实一点：既然必须要工作，那就想办法找到一份相对合适的工作。

第二阶段的十八年，清醒最重要。清醒地知道自己需要钱，清醒地去找工作，这就是务实。

## 二、实习：正式工作前的「预科班」

在找工作之前，找实习是大学生必须要面临的问题。

### 2.1 实习的4种核心类型

| 类型      | 转正可能性              | 招聘时间       | 适合人群      | 核心特点                     |
| ------- | ------------------ | ---------- | --------- | ------------------------ |
| 暑期实习项目  | 明确有 HC，转正率 30%-70% | 每年 2 月-6 月 | 冲刺大厂的核心路径 | 与校招流程完全一致，有明确转正 HC 和考核标准 |
| 可转正日常实习 | 潜在机会，取决于部门 HC      | 全年滚动       | 想留用的高年级学生 | 面向在校生，招聘难度低，流程简单         |
| 无转正日常实习 | 基本无                | 全年滚动       | 积累第一份经验   | 部门只是缺人干活，没有留用计划          |
| 提前实习    | 部分可直接获得暑期实习 HC     | 不固定        | 低年级的优秀学生  | 针对特别优秀的低年级学生开放           |

:::note
暑期实习项目是进入大厂最容易的路径，企业专门为校招提前批预留名额。如果你的目标是头部互联网公司，大三下学期一定要全力冲刺暑期实习。
:::

### 2.2 找实习的黄金时间线

| 年级    | 目标     | 说明                     |
| ----- | ------ | ---------------------- |
| 大二上学期 | 实习 1   | 不挑公司大小，核心是获得职场体验和基础技能  |
| 大二下学期 | 实习 2   | 开始向目标行业/岗位靠拢           |
| 大三上学期 | 实习 3   | 尽量进入行业内有一定知名度的公司       |
| 大三下学期 | 冲刺暑期实习 | **校招前最重要的实习，直接影响秋招结果** |
| 大四上学期 | 秋招正式批  | 正式求职阶段                 |
| 大四下学期 | 春招补录   | 补录阶段                   |

核心结论：校招简历中拥有 **2 份及以上相关实习经历**，竞争力会显著提升。第一份实习可以不相关，核心是积累通用能力；从第二份实习开始，尽量向目标岗位靠拢，形成连贯的职业经历。

### 2.3 实习薪酬与税务计算规则

实习生工资通常按 **劳务报酬** 计税：

| 规则            | 说明                                      |
| ------------- | --------------------------------------- |
| 起征点           | 800 元                                   |
| 适用税率          | 20%                                     |
| 每次收入 ≤ 4000 元 | 应纳税所得额 = 收入额 - 800 元                    |
| 每次收入 > 4000 元 | 应纳税所得额 = 收入额 × (1-20%)                  |
| 退税政策          | 全年总收入不超过 6 万元的，可在次年 3 月个人所得税汇算清缴时申请全额退税 |

:::important
很多人不知道实习生也可以退税。如果你实习期间被扣了税，记得在次年 3 月去个人所得税 APP 申请退税，这笔钱是可以拿回来的。
:::

### 2.4 如何判断转正 HC

HC = Headcount（人头数），在实习转正语境中，特指 **企业年度/季度预算内获批的、专门用于从实习生中招聘正式员工的编制名额**。它是实习转正的 **必要非充分条件**——没有 HC，哪怕你表现再优秀，部门想留你也留不住。

| 判断方法    | 具体操作                                     | 判断依据                      |
| ------- | ---------------------------------------- | ------------------------- |
| 面试时直接问  | "这个岗位今年有几个转正 HC？""去年转正率是多少？""转正考核标准是什么？" | HR 含糊其辞、回避问题 → 大概率没有明确 HC |
| 看官方信息   | 暑期实习项目 JD 通常标注"有转正机会"                    | 有标注 → 有明确计划；无标注 → 默认没有    |
| 查对应全职岗位 | 搜公司官网或招聘平台有无对应全职岗位                       | 有 → 部门确实有招人需求             |
| 实习过程中观察 | 有无明确转正时间节点和答辩安排；领导是否主动聊过转正意向             | 有 → 转正可能性高                |

:::caution
**最常见的坑**："表现好就可以转正"——这句话大概率是画饼。没有明确 HC 的承诺，再努力也可能白干。面试时不要问"有没有转正机会"，要问"有几个转正 HC"。
:::

## 三、渠道：哪些地方真的能找到工作

### 3.1 校园渠道（最容易）

| 渠道               | 说明              | 优势                           |
| ---------------- | --------------- | ---------------------------- |
| 学校就业信息网/就业指导中心   | 学校官方发布的实习、校招岗位  | 针对性强，多为面向本校学生的专属岗位，竞争更小      |
| 校园招聘会、企业专场宣讲会    | 春招/秋招双选会、大厂进校宣讲 | 可现场投递简历、直接和 HR 沟通，通过率远高于线上海投 |
| 辅导员、专业课老师、学长学姐内推 | 老师手里常有合作企业的内推名额 | 可直接跳过部分筛选环节                  |

:::tip
不要不敢问，主动就会有故事。辅导员和专业课老师手里的内推资源，往往比你自己海投效率高得多。
:::

### 3.2 综合招聘平台（岗位数量多）

| 平台          | 特点                         | 适合行业     |
| ----------- | -------------------------- | -------- |
| BOSS 直聘     | 可直接与 HR 或负责人沟通，**反馈快**     | 互联网与新兴行业 |
| 前程无忧（51job） | 老牌招聘网站，职位库庞大               | 南方城市影响力强 |
| 猎聘          | 综合能力突出，**中高端岗位资源丰富**       | 中高端岗位    |
| 智联招聘        | 企业资源丰富                     | 白领与中高端岗位 |
| 58 同城招聘     | 覆盖广，岗位类型齐全                 | 快速找工作    |
| 拉勾网         | 以 **互联网行业** 为主，岗位信息真实度高    | 互联网      |
| 易展翅         | **年轻人职业成长服务平台**，专注大学生实习、就业 | 大学生专属    |

### 3.3 小红书（被很多人忽略，但很有实用性）

可能有人会疑惑，**小红书不是用来种草的吗？** 但其实现在它已经是年轻人找实习的新渠道。

**为什么小红书有求职信息？**

- 小红书基本上是 **18-35 岁年轻人**，与求职者年龄有高度重合
- **对于企业来说**：在主流平台发布职位、下载简历、置顶推广等均需付费，招聘成本持续攀升，而 **小红书招聘成本低、触达精准**
- **对个人**：**求职者** 可展示个人能力，**增加被发现机会**；对于 **提供大厂内推的人** 来说，如果成功招到了合适人选，可获得公司 **回报**

**怎么找？**

| 方式        | 操作                                                    |
| --------- | ----------------------------------------------------- |
| 关注官方与认证账号 | 企业官方招聘号（如"京东招聘""美团招聘"）、认证 HR 或猎头账号（带蓝色 V 标识）          |
| 精准关键词搜索   | 岗位名称 + 地点 + 求职类型；公司名 + 内推/直招；急招/继任/实习 + 关键词；内推码 + 公司名 |

**特别注意：**

| 注意事项    | 具体操作                                                        |
| ------- | ----------------------------------------------------------- |
| 信息真实性核验 | 优先选择官方认证账号，警惕"三无"账号（无头像、无简介、无历史内容）；在企业官网、BOSS 直聘、天眼查等平台交叉验证 |
| 个人隐私保护  | 不轻易提供身份证号、银行卡信息、家庭住址等敏感资料                                   |
| 警惕付费与诈骗 | 任何要求"先交钱"的内推、保录基本都是诈骗；拒绝"押金""保证金""服务费"                      |

:::caution
小红书上的信息鱼龙混杂，一定要交叉验证。优先选择带蓝色 V 标识的认证账号，警惕"三无"账号发布的信息。
:::

### 3.4 野路子渠道（成功率更高）

| 渠道   | 说明                           | 优势                                    |
| ---- | ---------------------------- | ------------------------------------- |
| 各类社群 | 求职群、拼饭群、撸猫群、拼车群等公司内部员工群      | 信息更新快、岗位真实度高、竞争人数少，很多急招岗位只会在内部群发布     |
| 人脉内推 | 优先级：学长学姐 > 辅导员/专业课老师 > 家长/亲戚 | 可直接跳过简历筛选环节，直达用人部门，**通过率是海投的 5-10 倍** |

:::important
人脉内推是成功率最高的渠道。很多急招岗位根本不会放到公开平台，只在内部群里流转。所以平时多积累人脉，关键时刻能帮你大忙。
:::

### 3.5 官方免费靠谱招聘平台

| 平台               | 特点                                           | 适合人群   |
| ---------------- | -------------------------------------------- | ------ |
| 中国公共招聘网（全国人社官方）  | 国企、事业单位、央企、各地大厂政企岗集中，所有岗位免费投递，无收费中介          | 体制内方向  |
| 国家大学生就业服务平台（国聘网） | 教育部主办，**应届生专属王牌平台**，海量校招、实习、央企校招岗位           | 校招重点蹲守 |
| 各地人社局人才网（本地人才网）  | 本地事业单位、国企、优质本地民营企业岗位，**事业单位编外、社区、国企属地岗高频发布** | 属地化求职  |
| 人事考试网            | 公务员、事业单位编制、三支一扶、国企统招考试公告                     | 考编必看   |

:::warning
**避坑**：凡是入职前收费（培训费、服装费、押金）的岗位，无论平台全部直接拉黑。正规招聘从不收费。

求职优先级参考：**人脉内推 > 校园渠道 > 国聘网 > 本地人才网 > 中国公共招聘网 > 商业招聘 APP**
:::

## 四、面试：从入场到离场的每一步

面试本质是双向选择，掌握三个环节的主动权能大幅提升通过率。

### 4.1 面试三阶段拆解

```
入场 → 自我介绍 → HR 提问 → 反问环节 → 离场
              ↓
         压力测试（穿插进行）
```

标准面试分为 **自我介绍 → HR 提问 → 反问环节** 三步。

### 4.2 HR 提问环节：提前预判，引导话题

HR 的所有问题都围绕两个固定方向展开，不存在"突发奇想"的提问：

- 基于你的 **自我介绍** 内容展开追问
- 深挖 **简历** 上的项目经历、技能细节和过往经验

**核心策略**：主动主导面试走向，通过回答有意识地把话题引向你准备充分的优势领域。提前准备 3-5 个完整的 STAR 法则故事，覆盖解决问题、团队协作、抗压能力等核心维度。

### 4.3 压力测试：保持冷静，侧面回应

压力测试是 HR 故意制造紧张氛围，考察你的情绪稳定性和应变能力，**不是真的对你不满意**。

**核心原则**：

- **绝对不要表现出明显的情绪波动**（生气、委屈、慌张、急于辩解）
- 不正面硬刚，采用"先认同 + 再补充 + 展优势"的侧面回答技巧
- 全程保持礼貌和专业的态度

| 常见压力问题                   | 错误回答                 | 标准应对模板                                                                               |
| ------------------------ | -------------------- | ------------------------------------------------------------------------------------ |
| "你什么时候可以入职？"（反复追问逼你立刻答复） | "我随时都可以"（显得急切，容易被压价） | "我需要和学校/现公司确认一下手续流程，最快可以在 X 周内入职。如果贵司有需要，我也可以提前开始远程准备工作。"                            |
| "我觉得你这个项目没什么技术含量"        | "这个项目其实很难..."（急于辩解）  | "您说得对，这个项目的基础技术栈确实不复杂，但我在过程中重点解决了 XX 痛点，通过 XX 方法把效率提升了 XX%，这让我对 XX 领域的业务逻辑有了更深入的理解。" |
| "你和其他候选人比有什么优势？"         | "我学习能力强，能吃苦"（空泛无说服力） | "我注意到这个岗位核心需要 XX 能力，我在 XX 项目中积累了完整的相关经验，能够快速上手独立工作。同时我对贵司的 XX 业务方向非常认可，愿意长期投入。"      |
| "如果这次面试没通过，你会怎么办？"       | "我会很失望"（暴露脆弱）        | "我会认真总结这次面试暴露的不足，针对性地提升自己。同时我非常认可贵司的文化和业务，希望未来还有机会合作。"                               |

:::note
压力测试考察的不是你的答案有多完美，而是你在压力下的反应是否稳定。保持冷静，不要急于辩解，侧面回应即可。
:::

### 4.4 反问环节：体现诚意，获取关键信息

反问环节不是"走过场"，而是你了解公司、判断岗位是否适合的唯一机会，同时也能体现你的思考深度和求职诚意。

| 推荐提问                                     | 价值                                   |
| ---------------------------------------- | ------------------------------------ |
| "贵公司对我面试的这个岗位有什么预期？希望我入职 3 个月内达成什么核心目标？" | 了解岗位真实要求和考核标准，判断自己是否能胜任，同时展示你对工作的责任心 |
| "我面试的这个岗位您认为未来会遇到什么主要挑战呢？"               | 提前了解工作中的难点，展示你的前瞻性和解决问题的意愿           |
| "如果顺利入职，有没有什么我能提前做准备的工作？"                | 表达强烈的入职意愿，给 HR 留下积极主动的好印象            |
| "请问这个岗位的薪资结构、福利待遇和休息制度是怎样的？"             | 这是你最关心的实际问题，一定要问清楚，不要不好意思            |

**绝对不要问的问题**：

- "公司是做什么的？"（说明你面试前没做基本功课）
- "加班多吗？"（换个方式问："这个岗位的日常工作节奏是怎样的？"）
- "有没有五险一金？"（正规公司都有，问这个显得非常外行）
- "我什么时候能知道结果？"（HR 会主动告知，面试最后再确认即可）

:::caution
反问环节是你唯一了解公司真实情况的窗口。不要浪费这个机会，提前准备好问题清单。
:::

### 4.5 面试底层逻辑：给 HR 发挥空间，反客为主

很多人面试失败是因为把自己放在"被审判"的位置，全程被动回答。正确的做法是：

- 把面试当成一次平等的业务交流，而不是一场考试
- 给 HR 足够的发挥空间，让他多说话，你从中获取更多公司和岗位的真实信息
- 通过有质量的提问和回答，引导面试的话题方向，让 HR 始终关注你的优势和岗位匹配度

## 五、筛选公司与避坑

### 5.1 通过融资轮次判断公司稳定性

| 融资阶段 | 企业稳定性 & 求职参考                       |
| ---- | ---------------------------------- |
| 已上市  | 资金充沛、组织规范、社保福利完善，裁员风险低，**优先投递**    |
| C 轮  | 商业模式成熟、盈利趋向稳定，岗位编制充足，应届生友好         |
| B 轮  | 业务高速扩张，招人需求大，但部分部门盈利未落地，留意业务赛道     |
| A 轮  | 产品验证阶段，业务波动大，岗位变动多，慎选非核心业务岗        |
| 天使轮  | 初创小团队，现金流不稳定，倒闭/裁员概率高，仅适合想创业历练的求职者 |

> 查融资渠道：企查查、天眼查、IT 桔子、企服平台。

### 5.2 避坑清单

| 危险信号                | 应对             |
| ------------------- | -------------- |
| 入职前收费（培训费、服装费、押金）   | 直接拉黑           |
| "高薪低门槛""轻松月入过万"     | 不符合市场规律，大概率有问题 |
| 三无账号（无头像、无简介、无历史内容） | 信息真实性存疑        |
| 要求提供社交账号密码、人脸识别     | 不合理请求，直接拒绝     |

:::warning
**最高警戒线**：任何要求先交钱的工作，一律是诈骗。正规招聘从不收费。
:::

## 六、出社会后的自我保护

既然要出社会了，难免遇到恶人。大家一定要学会保护自己。

**《为了见到最强大的自己》**：那篇文章详细讨论了恶人双标原则——用道德绑架他人，用利益解放自己的策略性操纵术。这里只举几个职场中的具体场景示例。

### 6.1 职场中的常见陷阱

| 场景         | 对方操作                    | 你的应对                |
| ---------- | ----------------------- | ------------------- |
| 要求无偿加班     | "年轻人要多奋斗"（道德绑架），但自己到点就走 | 保留工作记录，该下班就下班       |
| 承诺转正但从不兑现  | "表现好就可以转正"（画饼），但无明确 HC  | 面试时书面确认 HC，不要只听口头承诺 |
| 反复修改无意义的方案 | "这是为了锻炼你"（道德绑架），但浪费你的时间 | 问清楚修改标准，有据可依        |
| 酒桌上逼酒      | "不喝就是不给我面子"（服从性测试）      | 温和而坚定地拒绝，不需要过多解释    |

### 6.2 保护自己的基本原则

| 原则   | 说明                                              |
| ---- | ----------------------------------------------- |
| 利益至上 | 任何要求，如果不能给你带来实际利益，都可以直接拒绝。不要为了"面子"、"人情"牺牲自己的利益。 |
| 责任转移 | 不替别人背锅。当对方试图把责任推给你时，直接推回去："这是你自己的决定。"           |
| 保留证据 | 重要的承诺、工作安排，尽量留痕（邮件、聊天记录），避免口说无凭。                |

:::important
保护自己的同时，也要守住底线：这些方法只用于应对主动对你使用恶意的人，对真诚、善良、尊重你的人，永远用真诚和善良去对待。人不犯我，我不犯人；人若犯我，我必犯人。
:::

## 结尾：生涯的一环

2022 年 9 月，我第一次敲下 `printf("Hello World!")`，连分号是什么意思都不知道。那时候的我，完全想不到几年后会坐在电脑前，写一篇关于"如何找工作"的文章。

找工作这件事，说大不大，说小不小。它只是人生中的一个节点，而不是终点。找到一份好工作，固然值得庆祝；暂时没找到，也不必妄自菲薄。

重要的是，你要清楚自己在做什么、为什么做、以及接下来该往哪里走。

:::note
如果你正在找工作，祝你好运。如果你还在读书，早点准备。如果你已经工作，记得定期更新简历。
:::

:::tip
这篇文章不承诺让你找到"完美工作"，但希望能帮你少走弯路。
:::
