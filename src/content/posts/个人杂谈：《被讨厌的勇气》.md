## 序章：那段"敏感自卑"的日子

不敢说每个人，但大多数人，应该都会有一段敏感自卑的时期。

或许因为性格、或许因为外貌，或许因为物质，或许因为所有的所有、一切的一切。

凑巧，我也是。

孤独的我们并不孤独。

如果能够在那段时期，更早地接触这本书，或许能够早早地接纳自己，轻松地度过那段时期了吧。

但也许会是——懂了很多道理，却仍然过不好这一生。

人这一生，每个时段都有每个时段的课题。让我们拥有被讨厌的勇气，做好课题分离，珍惜当下，去沉浸地阅读这本书。

这本书，是岸见一郎与古贺史健合著的《被讨厌的勇气》。

***

## 一、这是一本怎样的书

它不是一本传统意义上的心理学教科书。

没有枯燥的概念堆砌，没有冗长的实验论证，没有"参考文献"和"研究综述"。它的全部内容，就是一位**愤世嫉俗的青年**与一位**精通阿德勒心理学的哲人**，在五个夜晚的对话。

听起来很"心灵鸡汤"？翻开之后你会发现——它是一本披着鸡汤外衣的**哲学入门书**，而且哲学浓度高到需要你反复品味。

### 1.2 作品定位

**"心理学三大巨头"之一**的阿尔弗雷德·阿德勒（Alfred Adler，1870-1937），是与弗洛伊德、荣格齐名的奥地利心理学家。他创立的"个体心理学"强调人的主观能动性与社会属性，反对"过去决定论"，主张人能通过自我选择创造人生。

:::note
很多人把阿德勒和弗洛伊德归为"同门"，其实两人最终决裂。阿德勒认为，**人的不幸不是由过去决定的，而是由现在"赋予"过去的意义决定的**。这一观点直接挑战了弗洛伊德的"心理创伤决定论"，也是这本书一切颠覆性观点的源头。
:::

这本书的特殊之处在于，它采用**古希腊哲学经典的"对话篇"形式**。一位"青年"（代表普通人的质疑与困惑）与一位"哲人"（代表阿德勒思想的化身）在五个夜晚展开辩论——青年的每一次抬杠，都是读者心里会有的疑问；哲人的每一次回应，都像在把一个顽固的结慢慢解开。

### 1.3 全书结构：五夜对话

| 夜晚  | 主题          | 核心论点                |
| --- | ----------- | ------------------- |
| 第一夜 | 我们的不幸是谁的错？  | 否定原因论，提出目的论         |
| 第二夜 | 一切烦恼都来自人际关系 | 自卑感、优越情结、人生不是与他人的比赛 |
| 第三夜 | 让干涉你生活的人见鬼去 | 课题分离；自由就是被别人讨厌      |
| 第四夜 | 要有被讨厌的勇气    | 共同体感觉、横向关系          |
| 第五夜 | 认真的人生"活在当下" | 自我接纳、他者贡献、人生是连续的刹那  |

五夜主题呈"**质疑—冲突—顿悟—接纳**"的螺旋上升模式。青年从第一夜的"愤世嫉俗"逐步走向第五夜的"活在当下"，读者也在旁观这场辩论的过程中，完成了属于自己的"被讨厌的勇气"心理建设。

## 二、两位作者：一对"哲学 + 写作"的黄金搭档

聊这本书，绕不开两位作者。一个是深谙阿德勒心理学的哲学家，一个是把"问答体"玩出花来的自由作家。两人相遇后一拍即合，用最不像"心理学书"的形式，写出了最颠覆常识的心理学书。

### 2.1 岸见一郎

日本哲学家、心理学家，1956 年生于京都。高中时便以哲学为志向，进入大学后屡次到老师府上进行辩论。京都大学研究生院文学研究系博士课程满期退学。1989 年起致力于研究专业哲学和阿德勒心理学，是日本阿德勒心理学会认定顾问。同时还在精神科医院为许多青年做心理辅导。

主要作品包括：译著阿德勒《个人心理学讲义》《人为什么会患神经病》，以及《阿德勒心理学入门》《幸福的勇气》《不完美的父母》《接受幸福的勇气》等多部著作。

### 2.2 古贺史健

自由作家，1973 年出生。以**对话创作**（问答体裁的执笔）见长，出版过许多商务或纪实文学方面的畅销书。他创作的极具现场感与节奏感的采访稿广受好评，采访集《16 岁的教科书》系列累计销量突破 70 万册。

近 30 岁时邂逅阿德勒心理学，并被其**颠覆常识**的思想所震撼。之后，连续数年拜访京都的岸见一郎并向其请教阿德勒心理学的本质。本书中他以希腊哲学的古典手法"对话篇"进行内容呈现，让深奥的心理学理论变得生动易懂。

### 2.3 创作缘起

古贺史健被阿德勒心理学"颠覆常识"的思想所震撼，决定将这种思想以大众易于接受的方式呈现。两人选择古希腊哲学的"对话篇"形式，是因为这种形式能够让读者通过青年（代表普通人的质疑）与哲人（代表阿德勒思想）的辩论，**层层深入地理解抽象的心理学理论**。

:::important
古希腊哲学的"对话篇"形式，最早可追溯到柏拉图的《理想国》《苏格拉底的辩护》等经典。两位作者借用了这种"一问一答、层层推进"的形式，本质上是在模拟"心理咨询"的过程：来访者（青年）不断抛出困惑，治疗师（哲人）不断引导来访者自己找到答案。
:::

这种写法的妙处在于：它不像教科书那样"灌输"，而像一位温和的朋友，坐在你对面，等你自己把想说的说完，然后用平静的语气点一句——"其实你不必这样"。

## 三、颠覆你常识的 6 把钥匙

如果说整本书只有一句话值得记住，那应该是：**"你的不幸，是你自己'选择'的。"**

如果你觉得这句话冒犯了你，那恭喜你，你已经触到了这本书的门槛。

阿德勒心理学之所以"颠覆"，是因为它从根本上否定了我们大多数人最熟悉的一套叙事——"我之所以变成这样，是因为我过去经历了 XX"。**阿德勒说：不，重要的不是过去发生了什么，而是你如何诠释过去，以及你"想"通过这种诠释达到什么目的。**

下面 6 把钥匙，是这本书的核心。每把钥匙都颠覆一个常识。

### 3.1 钥匙一：目的论——你的不幸，是自己"选择"的

阿德勒对弗洛伊德"**原因论**"的彻底反叛，构成了这本书最核心的颠覆性观点。

传统心理学（尤其是精神分析）认为：一个人现在的心理状态，**原因**在于过去的经历。童年被虐待 → 长大后不信任人；父母离婚 → 成年后害怕亲密关系。**过去 → 现在**，因果分明。

阿德勒提出了"**目的论**"：重要的不是过去"发生了什么"，而是你"如何诠释"过去，以及你"**想**通过这种诠释达到什么目的"。

书里有一个非常经典的案例。一位患有"脸红恐惧症"的女孩，她不敢向心仪的男生表白，将原因归咎于自己的病症。但阿德勒心理学认为——**她不是为了脸红恐惧症才不敢表白，而是为了"不敢表白"这个目的，才"需要"脸红恐惧症。** 病症成了她逃避失败的借口。

```
"原因论"叙事：
    过去受伤 → 心理创伤 → 现在痛苦
    （过去决定现在）

"目的论"叙事：
    现在想要某种目的 → 选择某种情绪/症状 → 达成目的
    （现在决定过去如何被诠释）
```

第一次读到这个观点时，我整个人是懵的。**"我的不幸是我自己选择的"？开什么玩笑？我为什么要选择让自己不幸？**

但仔细想想，确实如此。**"我之所以一直走不出那段感情，是因为我还没准备好走出来"**——这句话听起来残忍，但细品之下，是不是有那么一点真实？**我们害怕的不是"走不出来"，而是"走出来之后那个未知的自己"。**

:::caution
目的论不是"受害者有罪论"。阿德勒并非在指责那些正在受苦的人"你活该"，他只是在指出一个心理学事实：**情绪往往是达成某种"目的"的工具，而那个目的，常常连我们自己都没意识到。** 看见这个目的，是改变的第一步。
:::

### 3.2 钥匙二：自卑感 ≠ 自卑情结

阿德勒有一句几乎被引用到烂的名言："**人类的烦恼，全都是人际关系的烦恼。**"

自卑、焦虑、孤独、愤怒、嫉妒……所有这些情绪的根源，都在于我们如何与他人相处。在与人相处时，我们总会产生一种感觉——**自卑感**。

阿德勒心理学对"自卑"做了极其重要的区分：

| 类型   | 定义                  | 作用      | 例子                    |
| ---- | ------------------- | ------- | --------------------- |
| 自卑感  | 感觉"我不够好"            | 健康的成长动力 | "我英语不好，所以我要学"         |
| 自卑情结 | 用"我不够好"作为**不行动**的借口 | 病态的逃避机制 | "我英语不好，所以我不去尝试"       |
| 优越情结 | 故意展示"我比你强"以掩盖内心自卑   | 反向的自我保护 | "考 100 分不算什么，我根本没认真学" |

**自卑感**是正常的心理，是推动我们成长的动力——"我不够优秀，所以我要努力"。但**自卑情结**则是用自卑作为逃避行动的借口——"我自卑，所以我不敢努力"。**本质是不想承担失败的风险。**

而"**越自负的人越自卑**"这句话，是阿德勒心理学最扎心也最精准的洞察之一。**一个处处炫耀自己的人，内心深处往往住着一个害怕"从高处跌落"的脆弱小孩。** 越用力地证明自己强，越说明内心有多害怕承认自己弱。

### 3.3 钥匙三：课题分离——人际关系烦恼的"万能解药"

如果说这本书只能让你记住一个方法，那一定是"**课题分离**"。

**简单定义**：分清"这是谁的事"。

**判断标准**：谁承担事情的最终结果，就是谁的课题。

```
              课题分离决策树
              
       这件事的结果由谁承担？
              /          \
            是我          是别人
            /              \
   这是我的课题        这是别人的课题
   → 我要负责          → 我无权干涉
   → 我要承担          → 也无需负责
```

举个例子：

- **父母希望我考研，但我更想工作** → 父母希望我考研是父母的课题；我选择工作是我的课题。**父母可以表达期待，但无权替我决定。** 同样地，父母对我决定的失望是父母的情绪，我不需要为他们的情绪负责。
- **朋友找我借钱，我不愿意** → 借不借是我的课题（我有处分自己钱的权利）；朋友怎么处理借不到钱是他的课题。**我拒绝，不代表我不近人情；我接受，也不代表我软弱。** 关键是我清楚自己为什么做这个选择。
- **同事在背后说我坏话** → 同行的嘴是他的课题；我怎么看待"被说坏话"是我的课题。**我无法控制他的嘴，但我可以选择不让他的话绑架我的心情。**

:::caution
课题分离的真正难点，不在于"识别"，而在于"**执行**"。

我们的大脑已经被"在意别人评价"训练了二十多年，突然被告知"那不是你的课题"，心理上会产生巨大的**失衡感**。你会在意别人说"你怎么这么自私""你怎么这么冷漠"——但请记住，**这些评价本身，也是评价者的课题，不是你的。**
:::

课题分离不是冷漠，不是自私，而是**建立清晰的人际边界**。不为别人的评价内耗，不为别人的期待而活。

### 3.4 钥匙四：被讨厌的勇气——自由的代价

理解了课题分离，自然会推导出这本书书名的核心理念——**被讨厌的勇气**。

很多人误以为"被讨厌的勇气"是教你如何对抗他人、如何孤僻、如何"我行我素"。实则完全相反。

**真正的"被讨厌的勇气"是：你不可能让所有人满意，只要你坚持自我、不迎合他人，一定会有人讨厌你。为了不被讨厌而迎合所有人的期待，压抑真实想法，最终失去自我。**

这个逻辑的残忍之处在于——**它揭示了自由的代价**。

```
"没有自由的虚假安全"：讨好所有人 → 没有自我 → 表面安全 → 内心空洞
"有自由的真实风险"  ：做真实的自己 → 可能被讨厌 → 表面危险 → 内心丰盈
```

书里有一句几乎封神的金句："**八面玲珑地讨好所有人的生活方式是一种极其不自由的生活方式。**"

还有一句更直接的："**不想被人讨厌'也许是我的课题，但'是否讨厌我'却是别人的课题。**"

这两句话，**单独拎出来一句就够一个人琢磨半年的**。

### 3.5 钥匙五：共同体感觉——幸福的终极答案

如果你以为做到"课题分离"和"不怕被讨厌"就完事了，那你只看到了这本书的一半。

阿德勒的野心不止于此。仅仅"不被人际关系绑架"，会不会让人陷入孤岛般的孤立？**他给出了更高的追求——共同体感觉。**

**共同体感觉**，不是一种感觉或情感，而是一种**将他人视为伙伴而非竞争对手的生存视角**。

我们习惯生活在"**纵向关系**"中：比较、竞争、追求优越感。学生时代比成绩，职场里比薪资，朋友圈里比生活……**纵向关系里，没有赢家**——你赢了这一局，总有下一局在等你。

而"**横向关系**"倡导的是：虽然不同但平等，每个人都有自己的位置和价值。**我不需要比你强，我也接受你不比我强，我们只是不同。**

| 关系类型 | 核心逻辑     | 典型台词                 |
| ---- | -------- | -------------------- |
| 纵向关系 | 比较、竞争、等级 | "你怎么能比我差""我必须比你好"    |
| 横向关系 | 平等、尊重、互补 | "我们是不同的个体，但都是共同体的一员" |

**幸福的公式**：

```
幸福 = 自我接纳 + 他者信赖 + 他者贡献
```

:::important
注意"他者贡献"的措辞——它不是"自我牺牲"，不是"为他人而活"，而是**主动选择"我对他人有用"的感觉**。哪怕只是帮人指个路、扶个门、在朋友圈点个赞，**只要你感觉自己"对别人有价值"，勇气就会油然而生**。
:::

### 3.6 钥匙六：活在当下——人生是一连串的刹那

这是第五夜的核心，也是整本书的收束。

阿德勒心理学强烈否定为人生设定遥远的、线性的目标。它认为，**人生不是一条通往某个山顶的直线，而是无数个"点"的连续**。我们只能活在"此时此刻"，人生的意义也只在"此时此刻"被赋予。

```
"线性的未来观"：
    起点 ────────── 目标（山顶）
                    ↑
                  此刻在"通往目标"上

"当下的连续观"：
    此刻 〇 ─ 此刻 〇 ─ 此刻 〇 ─ 此刻 〇
              ↑
         每个点都是完整的"人生"
```

书里有一句非常美的比喻："**人生就像是在每一个瞬间不停旋转起舞的连续的刹那。** 跳舞本身就是目的，最终会跳到哪里谁都不知道……但是，并不存在目的地。"

听起来很"佛系"？但这不是"摆烂"，而是"**认真活在当下**"。

**人生最大的谎言，就是纠结于过去、关注未来，却唯独忽略了"现在"。** 当你下定决心认真过好每一个"此时此刻"，人生便在每一个当下完整地展开。

**人这一生，如果非要用什么来丈量，大概不是年月的累加，而是那些突然之间、毫无预兆地、把你从一个人变成另一个人的时刻。**

## 四、那些"击中灵魂"的金句

这本书的金句密度极高，几乎每一节都有让人眼前一亮的精炼表达。我按主题精选了 12 条最戳的：

| 主题     | 金句                                    |

## 五、争议与讨论

这本书爆红之后，争议就没断过。

### 5.1 "心理创伤并不存在"是否过于绝对？

书中最具争议性的观点，是阿德勒完全否认"心理创伤"的存在——他认为"任何经历本身并不是成功或者失败的原因"。

这一观点在专业心理学界引发了巨大争议。批评者认为，作者完全否认心理创伤其实是**过于简化心理问题的复杂性**，忽略了创伤需要专业心理干预的事实，一味强调此时此刻的勇气，忽视了心理习惯的转变是一个长期的过程。

**回应**：阿德勒并非否认创伤事件的存在，而是否认"创伤必然导致痛苦"的因果关系。他认为，痛苦来自于我们对创伤的"诠释"而非创伤本身。但这并不意味着严重的心理创伤不需要专业治疗。

### 5.2 是否属于"毒鸡汤"或"成功学"？

由于书中观点大胆、语言精炼，有人将其归类为"毒鸡汤"或"成功学"。

**回应**：与成功学不同，阿德勒心理学不承诺"成功"，只承诺"幸福"。而且它对"幸福"的定义是"贡献感"而非"成就感"。书中甚至强调"**甘于平凡的勇气**"，这与成功学的"追求卓越"截然相反。

### 5.3 "课题分离"是否会导致冷漠？

有人担心，过度强调"课题分离"会让人变得冷漠、自私，不顾他人感受。

**回应**：书中明确区分了"课题分离"与"冷漠"。**课题分离是"建立人际边界"，不是"切断人际关系"。** 恰恰相反，只有在清晰的边界基础上，才能建立真正的"共同体感觉"和"他者贡献"。

:::warning
**严重警告**：本书不是"答案"，而是"视角"。如果你正深陷严重的抑郁、焦虑、创伤后应激，**请先寻求专业心理咨询师的帮助**，本书可作为辅助读物，但绝不可单靠它"自救"——这一点，请务必放在心上。
:::

## 六、阅读建议 & 适合谁

### 6.1 强烈推荐

- 过度在意他人评价、讨好型人格
- 深陷人际关系烦恼、社交焦虑
- 习惯将不幸归咎于原生家庭或过去
- 渴望自由却害怕被讨厌
- 对人生意义感到迷茫

### 6.2 谨慎阅读

- 严重抑郁症或焦虑症患者（建议配合专业治疗）
- 刚经历重大创伤事件
- 极度理性、排斥感性体验的读者
- 期待"快速成功秘籍"的读者

### 6.3 阅读建议

资深读者的"忠告"：

1. **不要一次性读完**：每一夜的内容都值得反复品味，建议分五天阅读，每天读一夜。**这是一本需要"发酵"的书。**
2. **带着质疑阅读**：像书中的"青年"一样，对哲人的观点提出质疑，不要全盘接受。
3. **结合实践反思**：每读完一章，回顾自己生活中是否有类似场景，尝试用新视角审视。
4. **与《幸福的勇气》配合阅读**：续作更侧重实践方法，两本配合效果更佳。
5. **不要孤立地理解"课题分离"**：课题分离只是手段，最终目标是"共同体感觉"。
6. **区分"理论"与"现实"**：书中是理想模型，现实中需要灵活应用。

## 尾声：保持自洽，这一生便足够了

写到尾声，我忽然想起开篇那段"敏感自卑"的日子。

那时候的我，如果能读到这本书，会不会真的"轻松地度过"？我不知道。也许会的，也许不会——**懂了很多道理却仍然过不好这一生，本就是常态**。

但至少，这本书会递给你一面镜子，让你看见自己一直在"用过去解释现在"的小把戏；递给你一把剪刀，让你剪断那些不属于你的课题；递给你一句咒语——**"这是谁的课题？"**

你之所以不幸福，可能不是因为你"不够好"，而是因为你**缺乏获得幸福的勇气**。这种勇气，是接纳不完美的自己的勇气，是不再寻求他人认可的勇气，是承担起自己人生全部责任的勇气，更是即便可能被讨厌也要按照自己心意生活的勇气。

人这一生，每个时段都有每个时段的课题。**学生时代有学生时代的课题，职场新人有职场新人的课题，为人父母有为人父母的课题，退休之后又有退休之后的课题。** 课题无穷尽，烦恼也就无穷尽——这本身就是人生的一部分。

那我们能做什么呢？

**永远保持自洽，这一生，便足够了。**

**做到自圆其说，这一生，便圆满了。**

所谓"自洽"，不是固执己见，不是自我安慰，而是**我理解了自己的课题，承担了我该承担的，放下了我不该承担的，并且在每一个"此时此刻"都尽量认真地活**。

所谓"自圆其说"，不是编造一个完美的人生故事，而是**用我自己的方式，把我走过的路、读过的书、爱过的人、犯过的错，编织成属于我自己的、唯一的"意义"**。

你也可以。

合上这本书的那一刻，请记得：**人生是一连串的刹那**。**重要的不是过去，不是未来，是你现在翻过的这一页。**
