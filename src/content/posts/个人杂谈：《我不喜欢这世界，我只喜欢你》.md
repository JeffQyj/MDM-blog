:::tip
2024 年的双十一，我没去抢满减，也没在购物车里加什么。这一天，我想聊一本和"买"无关、和"爱"有关的书——《我不喜欢这世界，我只喜欢你》。
:::

## 序章：那个高一刚开业的书店

第一次接触这本书，是高一。

具体日期早已模糊，但那一年学校刚开了一家现代化的书店——玻璃门面，木质书架，空气里还带着新书和油漆混合的气味。我记得很清楚，因为它是学校引进的第一家"像样"的书店，开业那天围了不少人，大家都想去看看那个传说中"装修花了多少钱"的地方。

开业酬宾，店家搞了一个很聪明的活动：拆封的书可以免费阅读，没拆封的再正常售卖。

对于一个高一学生来说，"可以免费看"四个字，比任何促销海报都有杀伤力。我挤进人群，开始在那排拆封的样品书前流连——挑的时候没有任何标准，就是随手翻、看封面、看插图、扫一眼前几段顺不顺眼。

好巧不巧，我翻到了这本。

当时的我，大概只是觉得封面配色干净、标题文艺、目录里那些"和摩羯男谈恋爱大概是这样的"看起来挺有趣。谁能想到，就是这么一次随手一翻，让我对"爱情"这两个字的理解，被悄悄改写了。

:::note
很多年后我才意识到，"第一次读一本书"和"之后的所有重读"是两回事。初读是信息输入，重读才是价值观塑形。这本书对我最大的影响，是它**用真实打败了虚构**——原来最好的爱情故事，不是霸道总裁爱上我，而是校服同桌从 16 岁到 26 岁。
:::

它不长，一个晚上就能翻完。

可它也很长，它不长在字数，它长在它所开启的、关于"好的爱情是什么模样"的整段思考。

这本书，是乔一写的《我不喜欢这世界，我只喜欢你》。

***

## 一、这是一本怎样的书

它不是一本传统意义上的小说。

如果你期待的是跌宕起伏的剧情、勾心斗角的家族恩怨、生离死别的虐恋桥段，那这本书会让你失望——因为它的全部剧情，就是两个普通人的十年日常。但偏偏，就是这种"普通"，让它在豆瓣拿到了 8.0 分，被无数读者称为"最甜的回忆录"。

### 1.1 基本信息

| 项目   | 内容              |
| ---- | --------------- |
| 书名   | 《我不喜欢这世界，我只喜欢你》 |
| 作者   | 乔一              |
| 出版社  | 湖南少年儿童出版社       |
| 出版时间 | 2015 年 5 月      |
| 定价   | 39.80 元         |
| 页数   | 208 页           |
| 装帧   | 精装              |
| 类型   | 爱情回忆录 / 随笔集     |
| 豆瓣评分 | 8.0 分           |

### 1.2 作品定位

乔一本人在书里说，自己"不是作家，是平淡生活的记录者"。

这本书最初源于她天涯论坛的年度热帖，后来在微博持续更新，文字真实幽默、故事温暖动人，结集出版后意外爆红。它采用\*\*"片段式跳跃叙事"\*\*——不是按时间顺序平铺直叙，而是像翻看一本私人相册，从高中跳到婚后，从甜蜜跳到争吵，从 F 君跳到哥哥观潮。零散却真实，平淡却动人。

### 1.3 全书结构

全书 18 章加番外、附录，约 7.2 万字。按主题大致可以分成 5 个模块：

| 模块   | 涵盖章节                  | 核心表达                   |
| ---- | --------------------- | ---------------------- |
| 婚后日常 | 第 1 章、第 8 章、第 9 章     | 奠定甜蜜基调，建立"结果已知"的阅读安全感  |
| 校园回忆 | 第 2-3 章、第 12 章        | 追溯感情源头，制造青春的 nostalgia |
| 重逢复合 | 第 5 章、第 10-11 章       | 完成从"错过"到"相守"的转折        |
| 亲情友情 | 第 4 章、第 6 章、第 16-17 章 | 丰富故事层次，衬托主线爱情的珍贵       |
| 反思总结 | 第 7 章、第 20-22 章       | 升华主题，传递爱情观与人生观         |

## 二、乔一、F 君与他们的十年

这本书之所以动人，一半归功于乔一的文笔，另一半归功于**F 君这个人**。

### 2.1 故事时间线

| 阶段   | 时间   | 关键事件                                |
| ---- | ---- | ----------------------------------- |
| 高中时期 | 16 岁 | 乔一与 F 君成为同桌，开学第一天 F 君扶了差点摔倒的乔一      |
| 毕业分离 | 高三毕业 | 散伙饭上 F 君隐晦告白被拒，两人绝交                 |
| 断联期  | 大学六年 | F 君赴英国留学，两人多年未联系；乔一大学期间短暂谈过一个月的其他男友 |
| 重逢复合 | 工作后  | 高中六十周年校庆重逢，恢复联系，慢慢走到一起              |
| 结婚成家 | 26 岁 | 从校服到婚纱，终成眷属；养了一只叫 dollar 的狗         |

### 2.2 四大人物群像

**乔一（女主/作者）**

感性浪漫、单纯善良、有点自卑的平凡女孩。感性多于理性，爱哭、爱闹、爱试探，但关键时刻有孤勇。她在书里自称"运气一向不好"，把遇见 F 君当作这辈子最幸运的事。

**F 君（男主/丈夫）**

摩羯座，学霸，大男子主义、不善言辞、有洁癖、情商低但智商高。表面冷酷面瘫，实则深情专一。他把所有想与乔一分享的瞬间，都记在短信草稿箱里；他把"我永远是你的"说得云淡风轻，却让乔一为这一句辞掉了南方的工作。

**观潮（哥哥）**

乔一的亲哥哥，自恋、人缘好、经常欺负妹妹，但骨子里极其疼爱乔一。乔一腿部手术那天，他在楼道里很认真地想——"要是妹妹没挺过去，他就把名字改成她的，替她在这个世界上继续活。"

**郝五一（闺蜜）**

乔一的高中闺蜜，陪伴乔一走过青春岁月，是感情路上的见证者和倾听者。她是书里女性视角的补充，让整本书的甜宠不至于悬浮在两个人的真空里。

:::important
四个人，四种关系，但都指向同一个内核——**"爱是一种被看见的幸运"**。乔一被 F 君看见、被观潮护着、被五一陪着。这种被看见的体验，恰恰是很多读者在书里读到自己眼泪的真正原因。
:::

## 三、那些笑着笑着就哭了的细节

这本书最厉害的地方，是它**几乎没有什么"大场面"**，但每一个小细节都像一颗糖，咬开才发现里头还包着一颗盐。

### 3.1 同学录事件

高二文理分班前，大家都在写同学录。乔一买了同学录，让全班都写，最后才"顺理成章"地把本子放到 F 君面前。

他起初不乐意，说"无聊"。软磨硬泡才松口："放我这儿吧，我有空写。"

但他永远没空。一直到高二快结束，才想起来把同学录还给她。乔一满怀期待地打开——**留言只有八个大字：「好好学习，不要懒惰」**。

乔一差点气死。

后来她才知道，这家伙真的太有心机了——**同学录在他那儿，她就不得不经常主动去找他**；他则慢悠悠地把本子里所有男生的留言都看了一遍，确定没有"奸情"才放心，最后大笔一挥，随便写几个字敷衍交差。

:::note
看，这就是摩羯男的爱——嘴上敷衍，背地里算计。不是不爱，是把所有的小心翼翼都藏在"看起来不在乎"的外壳下面。多年后重读这个故事，我才第一次理解：**"好好学习，不要懒惰"** 翻译过来其实是——"我希望你的未来比现在好，而我想一直在你身边看着"。
:::

### 3.2 "我永远是你的"

这是整本书里最让我反复停顿的一段。

乔一随口问 F 君："有没有某件事情，你很确信你可以做到，从来没有怀疑过自己？"

他毫不犹豫地说："有啊，很多。"

她说："我跟你相反，我从来没有这种自信，对很多事情都没把握。"

F 君没再说话。他绕到乔一的右手边，让她走马路里面，低头说——

> "那你现在记住，有一件事你可以确定——**我永远是你的。**"
> ——《眼前人是心上人》

他说得云淡风轻。

后来，乔一就决定辞职去北京。

:::important
注意他的动作：绕到右边，让她走马路里面。这不是甜言蜜语，这是一个人**用身体语言告诉你——我把最危险的那一侧留给了自己**。好的爱情从来不是轰轰烈烈的宣言，是每一个看似无关紧要的小动作里，都藏着一份"我想护着你"的心意。
:::

### 3.3 志愿书的秘密

这个故事藏在乔一大二那年。

一个高中同学来长沙找乔一玩，聊天时随口说："我一直以为你读 C 大是因为 F。"

乔一愣了："什么？"

"你不知道吗？C 大跟 F 的学校每年都有交换生。当时我们填志愿，F 突然来问我，问我哥是不是读 C 大、现在在英国做交换生，我说是啊，**C 大每年都有名额**。他跟我要了我哥的 MSN。"

"可是他从来没跟我说过这些。"

直到那一刻乔一才明白：**F 君在很久以前，久到她还在瑟缩着逃避、把他推远的时候，就一声不吭地，把她计划进了他的未来。**

> "其实很早以前，早到我还在瑟缩着逃避着将他推远时候，他就一声不吭地，**把我计划进了他的未来**。"
> ——《那个男孩教会我的事》

:::note
读到这一段的时候，我第一次明白了什么叫"沉默的爱"。不是不肯说，是说得太早你听不懂，说得太晚又怕错过。F 君选了最笨的方式——**不告诉你我做的一切，但我要确保我们的未来有交集**。这种爱，太摩羯了，也太让人心疼。
:::

### 3.4 "夜长梦多，吃肚子里揣着省事"

这一段承包了我对"F 君情商"的全部怀疑和全部偏爱。

公司给乔一配了个助理小姑娘，有天问她："姐姐，你为什么这么早就结婚？"

"遇到合适的就嫁了呀。"

"可是，你怎么断定他就是合适的人呢？"

乔一想了想，反问："抛开上下级关系，你觉得我这个人怎么样？"

"干练，专业，能力强，关键是性格超 nice。"

乔一笑了："可我老公可不这么认为。在他眼里我幼稚、孩子气、笨手笨脚、永远长不大。"

"他太不了解你了！"

"才不是呢，"乔一眯着眼睛笑，"**全世界只有他最了解我。**"

晚上给 F 君打电话，她又问了一遍："你为什么这么早就跟我结婚？"

某人回答得简单干脆——

> "**夜长梦多，吃肚子里揣着省事。**"
> ——《三件小事》

:::caution
注意——**这是 F 君全书的"反差萌"高光**。他可以在前一秒深情地说"我永远是你的"，也可以在后一秒用最不解风情的方式表达"我怕你跑掉"。**再冷的人，也有他自己的温柔语法**。
:::

## 四、它写的不只是爱情

读第一遍的时候，我以为这只是一本甜甜的爱情书。

读第二遍，我开始看到 F 君的家教、观潮的护妹、五一的陪伴、乔一的自我成长。

读第三遍，我才真正看懂——**它写的是一个人在爱情里如何被治愈，又如何因为爱一个人而成为更好的人**。

### 4.1 主题一：从校服到婚纱

"从校服到婚纱"是这本书最核心的标签，也是最戳中这个时代的部分。

在快餐爱情盛行的时代，乔一和 F 君用十年时间证明：**慢热的爱情也可以很甜**。

他们的爱情之所以动人，在于它的"不完美真实"——F 君不是霸道总裁，而是"不会做家务但有洁癖"的直男；乔一不是完美女主，而是"又傻又呆又爱哭"的普通人。他们会吵架、会冷战、会面临职场和家庭的压力，但最终——

> "爱让我们成为更好的人。"

### 4.2 主题二：平淡日常中的爱情哲学

本书没有狗血三角恋、没有豪门恩怨、没有生离死别。有的只是**柴米油盐中的小事**。但正是这些小事，构成了爱情最坚实的底座。

书里展现的健康爱情观，可以总结成四件事：

| 维度    | 表现                           |
| ----- | ---------------------------- |
| 双向奔赴  | 乔一会为 F 君辞职赴京，F 君会把所有温柔都藏在细节里 |
| 有效沟通  | F 君会吼乔一"你不高兴要说出来"，而不是冷战      |
| 共同成长  | "爱让我们褪去身上青涩的棱角，穿越汹涌的人潮"      |
| 接纳不完美 | "我从来不想要什么更好的人，我只要眼前的人"       |

"真诚"是亲密关系的南风，能在不知不觉中融化所有隔阂。**爱情里其实没有那么多轰轰烈烈，更多的时候，是"你今天有没有好好吃饭"这一句**。

### 4.3 主题三：原生家庭与自我治愈

乔一在书里坦承父亲出轨离异的创伤，这让她一度对爱情缺乏信心。但 F 君的坚定和温柔，逐渐治愈了她的不安全感。

书里有一段关于"温柔"的话，我到现在还反复引用：

> "有些人充满戾气和恶意，是因为他们从未被人温柔相待过。我相信自己能始终温柔，是因为年少时遇到了善良的人。"
> ——乔一

:::important
原生家庭不是用来背一辈子的枷锁，而是用来被理解、被接纳、被超越的。**被一个对的人温柔对待，本身就是一种治疗**。
:::

### 4.4 主题四：成长与遗憾

书里有一句话击中过无数读者——

> "成长最遗憾的部分在于，我们总在最无知的年华里遇到最好的人，却不自知。"

这是青春的通病：16 岁的我们，对什么是好、什么是珍贵、什么是稍纵即逝一无所知。F 君同学录上"好好学习，不要懒惰"的敷衍、散伙饭上被拒绝的告白、C 大志愿里没说的秘密——**全是当时没读懂的伏笔**。

但也正因为有遗憾，"幸好最后是你"才显得那么珍贵。

## 五、金句拾遗

这本书的金句密度极高，几乎每翻几页就能划出一道线。我挑了 12 条最戳的，按"说这话的人"分类整理：

| 说这话的人 | 金句                                    |
| ----- | ------------------------------------- |
| F 君   | "我从来不想要什么更好的人，我只要眼前的人，你究竟什么时候才会懂？"    |
| F 君   | "遇见你那天起，我就没想过要分开。"                    |
| F 君   | "在我面前，你可以不用坚强。"                       |
| F 君   | "那你现在记住，有一件事你可以确定——我永远是你的。"           |
| 乔一    | "一辈子很长，要跟有趣的人在一起。"                    |
| 乔一    | "成长最遗憾的部分在于，我们总在最无知的年华里遇到最好的人，却不自知。"  |
| 乔一    | "一个人爱着另一个人是藏不住的。"                     |
| 乔一    | "我以前在书里看过一句话……遇到爱，遇到性，都不稀罕，稀罕的是遇到了解。" |
| 乔一    | "喜欢是渴望将好的一起分享，爱是愿意把坏的共同承担。"           |
| 乔一    | "我有一万个不喜欢这里的理由，可我爱的人在这里，我就在这里安了家。"    |
| 观潮    | "要是妹妹没挺过去，他就把名字改成她的，替她在世界上继续活。"       |
| 观潮    | "妹妹太要强，哥哥什么都帮不了，只能帮她哭。"               |

读这些句子的时候，你会有一种错觉：**乔一不是作家，是把日子过成了诗的普通女孩**。她不堆词、不炫技，只是把心里真实的话写下来——而恰恰是这种"不修饰"，让它比任何精雕细琢的金句都动人。

## 六、争议：这份"真实"到底有几分真

读这本书之前，几乎所有读者都会被它的"真实"标签吸引。

读完之后，关于"乔一和 F 君是否真实存在"的讨论，就成了它绕不开的话题。

### 6.1 质疑方的三个主要疑点

:::caution
这部分是客观事实陈述，不针对作者本人。我只罗列各方观点，不做评价。
:::

1. **人设过于偶像剧**：傻白甜+冷酷学霸，分开六年最终复合——这剧情太像《何以笙箫默》了，巧合得让人不太信；
2. **F 君从未露面**：饰演剧版 F 君的张雨剑公开表示"从未见过 F 君本人"；网络如此发达，却搜不到 F 君任何真实信息；
3. **作者本身极低调**：乔一本人在微博也很少露面，婚后几乎没有任何与 F 君的私人合照。

### 6.2 支持方的四个主要观点

1. 乔一早年在微博持续更新，时间跨度长，**内容细节非亲身经历难以写出**；
2. F 君不愿公开身份是个人隐私，**不能用"搜不到"来证明"不存在"**；
3. 即便有艺术加工，**情感内核的真实**才是这本书打动人心的根本；
4. 真实与否其实不影响阅读体验——**读者买的是共鸣，不是八卦**。

### 6.3 理性看待

我的看法是：**这个问题没有标准答案，也不影响我们爱这本书**。

正如一位读者所说——

> "或许原著党们早已发现其中的端倪，但由于对于这样的爱情太过憧憬，他们愿意去相信这是真的。"

一本书的价值，从来不在于它的情节是否 100% 真实，而在于它**能否让你在合上书的那一刻，对"爱"这件事多了一份相信**。

***

## 七、当它变成 35 集电视剧

2019 年，这本书被改编成电视剧《我只喜欢你》，由吴倩、张雨剑主演，35 集。

### 7.1 改编基本信息

| 项目   | 内容                    |
| ---- | --------------------- |
| 剧名   | 《我只喜欢你》               |
| 导演   | 王之                    |
| 主演   | 吴倩（饰赵乔一）、张雨剑（饰言默/F 君） |
| 首播时间 | 2019 年                |
| 集数   | 35 集                  |
| 类型   | 青春、爱情、校园              |

### 7.2 改编评价：褒贬不一

:::warning
剧版和书版的体验完全不一样——**看书你能感受到乔一的内心戏，看剧你只能看到角色的外在表现**。如果你时间有限，优先看书。
:::

| 维度   | 好评                | 差评                |
| ---- | ----------------- | ----------------- |
| 还原度  | 保留了书中大量名场面和经典台词   | 部分情节改编过大，失去原著韵味   |
| 演员表现 | 吴倩灵气十足，贴合乔一形象     | 张雨剑版 F 君过于面瘫，台词僵硬 |
| 剧本   | 支线丰满，增加了观潮和五一的感情线 | 剧情拖沓，部分桥段显得"尬"    |
| 整体   | 甜宠氛围到位，适合下饭       | 改编剧众口难调，原著党失望     |

总体而言，电视剧**成功在"平淡"**。看过太多夸张的青春故事，这样一个另类而温馨的平凡故事反而引起共鸣。和我当年看《请回答1988》时的感受类似——**最戳人的从来不是狗血，而是真实**。

## 八、阅读建议 & 适合谁

### 8.1 推荐阅读人群

- 喜欢甜宠文、治愈系爱情的读者
- 相信或向往"从校服到婚纱"爱情的人
- 喜欢轻松幽默文风、碎片化叙事的读者
- 处于感情迷茫期、需要"相信爱情"的人

### 8.2 不适合人群

- 追求强剧情、强冲突的读者（本书平淡日常为主）
- 对"真实回忆录"标签极度较真的人
- 不喜欢第一人称碎碎念文风的读者

### 8.3 阅读提示

资深读者的"忠告"：

- **不要睡前看**：第一，枕头会湿；第二，憋笑十分痛苦，要不大晚上发出猪叫般的笑声也很吓人。
- **如果你身边有单身狗**：一定要让他们读到这本书（不能只让我一个人狂吃狗粮）。
- **做好重读的准备**：这本书会塑造你的爱情观，而塑造是一个反复的过程——**你以为你看完了，其实你只是刚开始**。

## 尾声：在善变的人世间，看一看永远

写到这里，这本书被我翻来覆去地讲了很多。

但我知道，无论我怎么写，都写不出它本来的样子。**乔一的文字之所以动人，是因为她把生活过成了书；而我们之所以被打动，是因为我们在书里，看到了自己想过的生活**。

书的最后一章叫《在这什么都善变的人世间，我想看一下永远》。这个名字本身，就是答案。

合上书的那一刻，我想起高一那年，在那家刚开业的书店里随手翻开这本书的自己。

那时候的我，还不懂什么是"双向奔赴"，不懂什么是"原生家庭的代偿"，更不懂为什么一本 200 页的随笔集，能让一个十六七岁的少年开始认真地思考"我以后想要什么样的爱情"。

但我把它记下来了——记在随笔本里、记在和朋友的聊天里、记在每一次重新翻开这本书时的"原来如此"里。

**人的一生，会把小时候缺漏的读后感慢慢补全。**

小时候真的不理解，书，看了就看了，为什么还要求我们写读后感呢？

现在发现，这个行为没错，但是错位了。

**小时候的我们怎么会知道，我们会用一生去补全读后感呢。**
