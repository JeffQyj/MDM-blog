第五周也是一下就过去了。这周换了新的办公地点，真正进入了「未工作之前想象中的职场生活」。进而，本周的领悟浓缩成两个字——**祛魅**。
:::

## 一、祛魅：最好的方式就是拥有它

这周，我换了新的办公地点。

坐在新工位上的那一刻，我忽然意识到：**这里，就是我在未工作之前，无数次想象过的职场。**

想象里，职场是什么样子的？是电视剧里那种节奏紧张、精英穿梭的写字楼，是自己终于能独当一面、指点江山的舞台，是「工作了就是大人了」的某种神圣门槛。想象里的一切，都带着一层柔光滤镜。

然后我坐进了真实的工位。办公桌、显示器、早会、需求、排期、消息提示音——它们一起告诉我：哦，原来就是这样。

**很多东西，真正体验过后，才发现，其实也就那样吧。**

这句话不是抱怨，不是失望，而是一种很平静的释然。它让我想到了一个词——**祛魅**。

**祛魅（Disenchantment）**，最早来自德国社会学家马克斯·韦伯（Max Weber）在《以学术为业》里提出的「世界的祛魅」：现代化进程中，科学、理性、计算取代了宗教与巫术，世界不再有「不可知的魔力」，万事万物都能被解释和支配。

到了年轻人嘴里，这个词被梗化成了一个更朴素的动词——**打破滤镜、去掉光环、从仰视变成平视**。

**祛魅的最好办法，就是拥有它。**

## 二、知识的祛魅：只学那百分之十

对职场的祛魅，只是这周的表层。更深的祛魅，发生在「学习」这件事上。

这周依旧学了很多新东西，但没有专门的文章去介绍——因为它们真的只是「为了用而学」。学习内容大致是围绕 **SOLIDWORKS 二次开发**与**工业数据采集**两条线：

- **SOLIDWORKS API 开发**：前置知识清单，从 CAD 建模逻辑、编程语言选型、COM 底层原理到开发工具链，先把地基摸清
- **VBA 语法**：SW 内置的快速自动化路线，配合宏录制，是上手 API 最快的入口
- **C# 与 .NET 体系**：企业级插件与独立程序的主流工业开发路线，涉及 .NET Framework、互操作程序集
- **数据自动采集入库**：Python + openpyxl + psycopg2，把实验上位机与仿真工作站的数据自动采集入库 PostgreSQL
- **预测性维修**：纯规则诊断引擎，靠电流、温度这些天天在测的常规数据，提前判断设备「哪里不对劲」

工作中学到的东西，真的只是为了使用才去学的。什么意思呢？就是「百分百的东西，用来工作的，实质有百分之十就不错了」。为了完成一个需求、跑通一个业务，我们快速地把那 10% 学了、用了，剩下的 90% 完全不用去理解。

:::important
这不是偷懒，这是工作的默认规则。**需求的排期不会等你把原理啃完，业务也不会为「我想学扎实一点」买单。先让系统跑起来，再把原理慢慢补上——顺序对了，一切才对。**
:::

## 三、学生思维与工作思维：不是对错，是场景

学生思维是什么？——**做东西之前，要把需要学的东西，成体系地学习一遍。**

先学语法，再学原理；先搭认知框架，再动手实践。这是我从大学一路走来的惯性：考试大纲划好了，课程体系排好了，评价标准固定了，你只需要「学完再考」，就能拿到不错的成绩。体系化学习，曾经是我最熟悉、最安全的路径。

而工作思维是另一套逻辑：

| 维度   | 学生思维     | 工作思维      |
| ---- | -------- | --------- |
| 学习起点 | 先学后用     | 边用边学      |
| 学习范围 | 成体系、追原理  | 只学要用的 10% |
| 评价标准 | 掌握程度     | 交付结果      |
| 时间资源 | 充裕、可规划   | 紧张、被排期    |
| 风险态度 | 容错高，允许试错 | 要交付，结果说话  |

但学生思维没有错。成体系地学习，肯定能帮助我们更好地系统性掌握一个领域——它给你打地基、建框架，让你面对新问题时知道它长在体系的哪个位置。这是长期主义的根基，任何时候都不该丢掉。

工作思维也没有错。我们没有那么多时间去体系化地学习每一个用到的技术，以结果为导向，同样是正确的——它让你在资源有限时做出取舍，快速产出价值。这是当下主义的效率，是职场的生存法则。

:::caution
最怕的是在错误的场景里用错误的思维：在学校里用工作思维「速成」，考完就忘，地基永远是塌的；在职场上用学生思维「学完再做」，排期全拖，结果永远是迟的。**思维没有高下，用对场景才是本事。**
:::

## 四、被工作掏空的一周：廉价多巴胺与常态

一整天的上班时间，完全把我的前额叶资源消耗得七七八八。前额叶是大脑里负责理性决策、意志力、自我控制的那一部分——它像一个电池，白天被工作反复放电，到了下班时分，基本见底。

就算想在晚上进行知识补全和成长完善，也是有心无力。脑子转不动了，只剩一个念头：瘫着。于是下了班，我就用刷短视频获得的廉价多巴胺，去麻痹自己的疲劳。

短视频像一杯高压糖浆——甜是真甜，营养约等于零。它不给你任何成长，只给你即时的、廉价的兴奋感，让你暂时忘掉「今天好累」。但糖浆喝多了，你就更不想吃正经的饭了：本来该用来复盘、学习的精力，全被它稀释掉了。

或许，这就是常态吧。

祛魅的另一面，是承认**工作本身也只是普通的生活**。它不神圣、不宏大，就是每天八小时的体力与脑力交换，外加下班后一点点见底的自我恢复。学生时代以为「工作了就能一直打怪升级」，真相是「上班是打怪，下班是回血」，回血的方式还经常不太健康——但这不妨碍第二天继续上线。

## 五、草台班子与配得感

**别美化。**

别太美化任何人，任何事物。想象会给人或事加滤镜——名校的滤镜、大厂的滤镜、前辈的滤镜、职场的滤镜。但滤镜之下的真实分量，往往只有走近了才看得清。

可别美化不等于贬低。看清「他也只是普通人」，不意味着「他不过如此」的傲慢，而是意味着**我不再仰视，也不再自我贬低**。

网上有个很流行的说法：**世界是一个巨大的草台班子。** 意思是，那些看起来光鲜、专业的机构与体系，拆开看，不过是一群普通人用凑合的办法把事撑起来——PPT 是现改的，代码是有坑的，流程是缝缝补补的。

这句话不是贬义，反而是一种释然。它告诉你：**没有谁比你高到不可企及。** 大家都是各自台上的草台班子，努力演好各自的角色，不让台子塌下来而已。

**配得感。**

**配得感**，就是相信自己值得拥有眼前这一切的感觉。它的反面是「不配得感」——「我不够好」「我配不上这里」「我是不是运气好才进来的」。

而这周我想明白了：**当你能够出现在这个场合，你就一定配得上这个地方。** 招聘你的是这里，给你排期的是这里，把需求交到你手里的是这里——既然舞台让你上来了，你就不是观众席的看客，而是这个草台班子的一员。

:::warning
配得感不是自大，更不是躺平。它和「永远保持成长」并不矛盾——**你可以一边认为自己配得上这里，一边努力成为这里更值得的那个人。** 祛魅是对外部光环的降噪，配得感是对内部自我的加固，两件事要同时做：既不高估别人，也不低估自己。
:::

## 结语：第二个十八岁的功课

在[《为了见到最强大的自己》](../成长碎记为了见到最强大的自己/)里，我写过「两个十八年」：第一个十八年，身体在长成；第二个十八年（18-36 岁），精神在长成——人格塑造、自我觉醒、精神丰满。

前几周，我给它补上了「清醒」「从容」「耐心」，上一周加上了「永远的胜利者」。这一周，我再放上一块拼图——**祛魅**。

**祛魅，是我们第二个十八岁一定要做好的功课。** 因为只有看清世界真实的分量，我们才不会被滤镜骗走自信，也不会被光环吓退脚步。对职场祛魅，对知识祛魅，对他人祛魅——祛魅不是把世界看扁，而是把自己放正。

回顾这五周：

- 第一周，我在学「**匹配期待**」——把主动权握回自己手里；
- 第二周，我在学「**保持松弛**」——不被预设的难题拖垮；
- 第三周，我在学「**耐心**」——在解决不完的问题里稳住心态；
- 第四周，我在学「**永远的胜利者**」——重新定义什么叫做「赢」；
- 第五周，我在学「**祛魅**」——看清世界的真实分量，然后配得上它。

世界是一个巨大的草台班子，但我们一定要有配得感。

**你看清了它的普通，才不会被它的光环困住；你承认了自己的普通，才配得上所有不普通的机会。**
