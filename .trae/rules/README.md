## 阅读顺序建议

1. **首次接触**：先读 [文章工作流](./article-workflow.md) 的「决策表」与「核心规则」，理解协作边界
2. **撰写前**：再读 [文章约束条件](./article-constraints.md) 的 frontmatter、命名、分类等硬性规范
3. **创作中**：参考 [文章创作风格](./article-style.md) 的内容质量标准、文章结构、admonition 用法
4. **遇到疑问**：查阅 [正反例库](./article-examples.md) 的具体写法对照
