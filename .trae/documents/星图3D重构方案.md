# 星图 3D 重构方案

## 1. Summary（方案摘要）

将 `/tech` 页面中的「技术神经图谱」从 **Cytoscape.js + CSS 渐变星点** 升级为 **Three.js 真 3D 星空**，呈现深空写实风格：

- 真实 3D 球状节点 + Bloom 后处理发光，告别"豆子胶囊"
- 多层视差星点（远/中/近三层独立闪烁）+ 银河带星云，营造宇宙纵深
- 11 个分类聚成 11 个星座区域，按黄金角度分布在球面上
- 鼠标可自由旋转/缩放/平移视角，悬停节点弹出 3D 投影定位的 tooltip
- 自动慢速旋转（用户交互时停止），闲置时呼吸式浮动
- 性能优化：InstancedMesh 单 draw call 渲染所有节点，Out of View 时暂停渲染

### 3.3 数据流改造

**输入数据不变**（`tech-stack.ts` 输出的 70+ 节点仍用），仅在 `constellation-layout.ts` 中转换为 3D 坐标：

```typescript
// 输入：techStack: TechEntry[]，分类字段 category
// 输出：positioned: Map<id, {x, y, z, color, clusterId}>

function fibonacciSphere(n: number, radius: number): Vec3[] {
  // 黄金角度分布 11 个分类中心点（完美均匀）
  const points: Vec3[] = [];
  const phi = Math.PI * (3 - Math.sqrt(5));  // 黄金角
  for (let i = 0; i < n; i++) {
    const y = 1 - (i / (n - 1)) * 2;          // y 从 1 到 -1
    const r = Math.sqrt(1 - y * y);
    const theta = phi * i;
    points.push({ x: Math.cos(theta) * r * radius, y: y * radius, z: Math.sin(theta) * r * radius });
  }
  return points;
}
```

        if (obj instanceof THREE.Mesh || obj instanceof THREE.Line) {

          (obj.material as THREE.Material).dispose();

      });
      renderer.dispose();
      composer.dispose();
    });
  });

**`constellation-layout.ts` 核心算法**：

```typescript
import * as THREE from 'three';
import type { CytoscapeNodeData } from '@/types/tech';

// 11 分类色相映射（HSL 等距分布）
const CATEGORY_HUES: Record<string, number> = {
  'AI 与 Agent': 195,         // 青蓝
  '编程语言': 30,             // 金
  '前端框架': 270,            // 紫
  '后端框架': 145,            // 绿
  '数据库': 210,              // 蓝
  '中间件': 0,                // 红
  '云原生': 320,              // 玫红
  '工程化与工具': 60,          // 黄
  '数据科学与 AI': 180,        // 青
  '系统与底层': 240,           // 靛
  '设计': 15,                 // 橙
};

export interface PositionedNode {
  id: string;
  name: string;
  category: string;
  position: THREE.Vector3;
  color: THREE.Color;
  size: number;
  clusterCenter: THREE.Vector3;
}

export function computeConstellationLayout(nodes: CytoscapeNodeData[]): PositionedNode[] {
  // 1. 按分类分组
  const groups = new Map<string, CytoscapeNodeData[]>();
  nodes.forEach(n => {
    if (!groups.has(n.category)) groups.set(n.category, []);
    groups.get(n.category)!.push(n);
  });

  // 2. Fibonacci 球面分布分类中心
  const categories = Array.from(groups.keys());
  const clusterCenters = fibonacciSphere(categories.length, 80);

  // 3. 每个分类内随机散布在球冠内
  const positioned: PositionedNode[] = [];
  categories.forEach((cat, ci) => {
    const center = clusterCenters[ci];
    const hue = CATEGORY_HUES[cat] ?? 0;
    const color = new THREE.Color().setHSL(hue / 360, 0.6, 0.65);

    groups.get(cat)!.forEach((n, ni) => {
      // 球冠内均匀分布：基于斐波那契的局部变体
      const localPhi = Math.PI * (3 - Math.sqrt(5));
      const localY = 1 - (ni / Math.max(1, groups.get(cat)!.length - 1)) * 0.8;
      const localR = Math.sqrt(Math.max(0, 1 - localY * localY));
      const localTheta = localPhi * ni;
      const localPos = new THREE.Vector3(
        Math.cos(localTheta) * localR * 12,
        localY * 12,
        Math.sin(localTheta) * localR * 12
      );

      // 节点尺寸 = 基础 1.5 + 文章加成
      const postCount = n.relatedPosts?.length ?? 0;
      const size = 1.2 + Math.min(postCount, 4) * 0.2;

      positioned.push({
        id: n.id,
        name: n.name,
        category: cat,
        position: center.clone().add(localPos),
        color,
        size,
        clusterCenter: center,
      });
    });
  });

  return positioned;
}

function fibonacciSphere(n: number, radius: number): THREE.Vector3[] {
  const points: THREE.Vector3[] = [];
  const phi = Math.PI * (3 - Math.sqrt(5));
  for (let i = 0; i < n; i++) {
    const y = 1 - (i / (n - 1)) * 2;
    const r = Math.sqrt(1 - y * y);
    const theta = phi * i;
    points.push(new THREE.Vector3(
      Math.cos(theta) * r * radius,
      y * radius,
      Math.sin(theta) * r * radius
    ));
  }
  return points;
}
```

### 3.9 性能与边界

| 场景 | 策略 |
|------|------|
| 首屏 SSR | `client:only="svelte"`，避免 SSR 报错（Three.js 依赖 window） |
| WebGL 不支持 | 检测后显示静态降级：`<img>` 渲染预设星图 PNG + 文字提示 |
| 移动端 | 自动降低星点数量（远 1500/中 400/近 80），关闭 Bloom，关闭闲置旋转 |
| 标签溢出 | 当节点屏幕距离 < 5px 时才渲染标签（cull by distance） |
| 窗口失焦 | `document.visibilityState` 监听，隐藏时暂停 RAF |
| DPR 上限 | `renderer.setPixelRatio(Math.min(2, window.devicePixelRatio))` |
| 内存管理 | `onDestroy` 中 dispose 所有 geometry/material，cancelAnimationFrame |

## 4. Assumptions & Decisions（假设与决策）

| 决策 | 取值 | 理由 |
|------|------|------|
| 渲染栈 | Three.js 原生（非 React Three Fiber） | 项目用 Svelte 5，RTF 不适配 |
| 后处理 | 仅 Bloom（UnrealBloomPass） | 真实发光是星图灵魂 |
| 布局算法 | Fibonacci 球面 + 局部球冠 | 简单、均匀、无需第三方物理引擎 |
| 物理引擎 | 不引入 d3-force-3d / ammo.js | 70 节点规模不需要；静态布局 + 微动效足够 |
| 节点几何 | IcosahedronGeometry(1, 1) | 低面数 + 球感，比 Plane/Sprite 更立体 |
| 字体 | 沿用 JetBrains Mono Variable | 与现有 tooltip/HUD 一致 |
| 移动端降级 | 关闭 Bloom + 减少星点 | 性能优先于视觉 |
| 闲置旋转 | Y 轴 0.05 rad/s | 慢速，避免眩晕 |
| 数据契约 | `tech-stack.ts` 完全不动 | 70+ 节点 / 11 分类 / relatedPosts 全部复用 |
| Cytoscape 依赖 | 移除 | 已无用处，避免包体 |
