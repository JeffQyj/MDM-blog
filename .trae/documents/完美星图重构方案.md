# 完美星图重构方案（v2：问题诊断 + 完整重建）

> 目标：从「发光奶白色光斑灾难」重构为「深空写实、信息可读、视觉震撼」的真·完美星图。
> 用户决策：球面星座分布（升级）+ 所有技术节点同级（不差异化）。

---

## 1. Summary（方案摘要）

将 `/tech` 页面的 3D 神经图谱从**参数失控的全屏光晕**重构为**深空写实、信息清晰、视觉震撼**的完美星图。核心思路：

- **根治过曝**：把 Bloom 阈值从 `0.0` 提升到 `0.85`，让 bloom 只作用于真正的"亮源"而非所有像素
- **节点可读**：节点本体放大并采用自定义 shader 渲染「星点 + 十字芒」复合形态，光晕收敛到 1.8 倍而非 6 倍
- **银河带重做**：把当前 3 块亮色 Plane 替换为**深色尘埃带**（暗剪影叠加微弱紫色辉光），营造真实银河的「盘面」感
- **深空底色**：背景径向渐变中心亮度从 `oklch(0.16)` 降到 `oklch(0.05)`，让星点真正"亮"出来
- **保持球面星座**：11 分类在半径 80 的球面用 Fibonacci 均匀分布（保留现状）
- **同级节点**：所有技术节点形态一致（不再按 relatedPosts 差异化）
- **新增 4 类点缀**：流星（每 15s 一颗划痕）、节点点击涟漪、轨道环（仅在悬停时显示）、银河核心辉光

预期最终效果：黑得深邃、节点清晰、银河带能看出主结构、分类色辨识度高、悬停反馈丰富。

## 3. Proposed Changes（具体改动）

### 3.1 后处理彻底重做（`post-processing.ts`）

```typescript
// === 关键参数（从失控到克制）===
const bloomPass = new UnrealBloomPass(
  new Vector2(w, h),
  0.55,  // strength: 0.95 → 0.55（核心：减弱整体辉光）
  0.7,   // radius:   0.5  → 0.7（核心：柔化光斑边界）
  0.85,  // threshold:0.0  → 0.85（核心：只让真正亮的部分 bloom）
);
```

**为什么这样调**：
- `threshold=0` 是灾难源 → 提升到 0.85 后，只有节点中心、十字芒尖端、银河核心这种"真正亮"的像素才会发光，普通星点不会糊
- `strength=0.55` 配合 `threshold=0.85` → bloom 只在局部"亮源"周围形成适度光晕，不会全屏过曝
- `radius=0.7` 略微增大 → 让光晕更柔和、更自然

**新增二级后处理链**（可选）：
```typescript
// 1. RenderPass
// 2. UnrealBloomPass (克制)
// 3. ShaderPass: FilmPass（极弱胶片颗粒 0.15，避免画面过于"塑料"）
// 4. OutputPass
```

### 3.2 节点彻底重做（`star-nodes.ts`）

**当前问题**：节点本体小、光晕大、形态单一。

**新方案**：用自定义 ShaderMaterial 渲染「核心球体 + 十字芒 + 圆形光晕」三层复合。

```glsl
// 顶点着色器
varying vec3 vNormal;
varying vec2 vUv;
varying vec3 vViewPosition;

void main() {
  vUv = uv;
  vNormal = normalize(normalMatrix * normal);
  vec4 mvPosition = modelViewMatrix * vec4(position, 1.0);
  vViewPosition = -mvPosition.xyz;
  gl_Position = projectionMatrix * mvPosition;
}

// 片元着色器（核心：星点 + 十字芒复合）
varying vec3 vNormal;
varying vec2 vUv;
varying vec3 vViewPosition;
uniform vec3 uColor;       // 分类色
uniform float uHighlight;  // 0~1 高亮强度
uniform float uTime;       // 闪烁相位

void main() {
  // 1. 核心球体：Lambert + Fresnel
  float fresnel = pow(1.0 - max(dot(vNormal, normalize(vViewPosition)), 0.0), 2.0);
  float core = mix(0.5, 1.5, fresnel);  // 边缘亮、中心中等

  // 2. 十字芒（4 角光芒）：基于 UV 到中心距离
  vec2 dir = vUv - vec2(0.5);
  float cross = 0.0;
  // 横向芒
  cross += exp(-abs(dir.y) * 80.0) * exp(-abs(dir.x) * 6.0);
  // 纵向芒
  cross += exp(-abs(dir.x) * 80.0) * exp(-abs(dir.y) * 6.0);
  // 对角芒（弱）
  cross += exp(-abs(dir.x + dir.y) * 60.0) * exp(-abs(dir.x - dir.y) * 10.0) * 0.4;
  cross += exp(-abs(dir.x - dir.y) * 60.0) * exp(-abs(dir.x + dir.y) * 10.0) * 0.4;

  // 3. 圆形光晕：1.8 倍于节点（不再是 6 倍）
  float dist = length(dir);
  float halo = exp(-dist * 8.0) * 0.6;

  // 4. 闪烁（仅在非高亮态）
  float twinkle = 1.0 + 0.05 * sin(uTime * 2.0 + vUv.x * 10.0);

  // 5. 合成
  float intensity = (core + cross + halo) * twinkle;
  intensity *= 1.0 + uHighlight * 1.2;  // 高亮 ×2.2

  gl_FragColor = vec4(uColor * intensity, 1.0);
}
```

**几何体**：继续用 `IcosahedronGeometry(1, 1)` 渲染，但通过 UV 构造十字芒（球体贴图的展平近似）。

**尺寸调整**：
- `BASE_NODE_SIZE`: 1.3 → 2.0（节点本体放大）
- 取消 `POST_SIZE_BONUS`（用户要求同级，不再按文章数缩放）
- 光晕尺寸倍数：6 → 1.8

### 3.3 银河带彻底重做（`nebula.ts`）

**当前问题**：3 块亮色 PlaneGeometry 用 AdditiveBlending 叠加，整片糊掉。

**新方案**：用自定义 ShaderMaterial 渲染**深色尘埃带 + 微弱紫色辉光**（真实银河的"暗带剪影"）。

```glsl
// 片元着色器（核心：噪声扰动 + 中心暗 + 边缘微亮）
varying vec2 vUv;
uniform float uTime;
uniform vec3 uColor;
uniform float uOpacity;

// 哈希噪声函数
float hash(vec2 p) { return fract(sin(dot(p, vec2(127.1, 311.7))) * 43758.5453); }
float noise(vec2 p) {
  vec2 i = floor(p), f = fract(p);
  return mix(mix(hash(i), hash(i + vec2(1, 0)), f.x),
             mix(hash(i + vec2(0, 1)), hash(i + vec2(1, 1)), f.x), f.y);
}
float fbm(vec2 p) {
  float v = 0.0; float a = 0.5;
  for (int i = 0; i < 5; i++) { v += a * noise(p); p *= 2.0; a *= 0.5; }
  return v;
}

void main() {
  // UV 坐标：横向为带长方向，纵向为带宽方向
  float bandFalloff = 1.0 - smoothstep(0.0, 0.5, abs(vUv.y - 0.5) * 2.0);
  // 横向波动：FBM 噪声扰动
  float wisp = fbm(vec2(vUv.x * 8.0, vUv.y * 2.0 + uTime * 0.03));
  // 中心更暗（尘埃带），边缘有微弱辉光
  float center = smoothstep(0.0, 0.3, abs(vUv.y - 0.5) * 2.0);
  float dust = (1.0 - center) * wisp * 0.4;  // 暗色尘埃
  float glow = center * 0.15;                 // 边缘微亮
  float alpha = (dust + glow) * bandFalloff * uOpacity;
  gl_FragColor = vec4(uColor, alpha);
}
```

**结构调整**：
- 从 3 块大 Plane 改为**1 块贯穿场景的银河主带**（PlaneGeometry 3000x400）
- 银河带倾斜 -15° 绕 X 轴，绕 Y 轴慢速旋转（0.005 rad/s）
- 主带中心叠加**球状核**（半径 30，亮度 0.6，模拟银心）
- 主带两端外侧叠加**2 块辅助云气**（带紫色辉光）

## 8. 风险与回退

| 风险 | 影响 | 回退方案 |
|------|------|----------|
| Shader 编译失败（显卡驱动差异） | 节点/银河带不可见 | 准备 WebGL2 降级路径（用 `MeshBasicMaterial` 简化版） |
| 十字芒 shader 视觉过亮 | 节点仍可能过曝 | 二次调参：把 `cross` 项系数从 1.0 降到 0.6 |
| 银河带太暗看不出 | 失去银河感 | 调高 `uOpacity` 从 0.5 到 0.8 |
| 流星动画卡顿 | 性能问题 | 用 `Points` 替代 PlaneGeometry |
| 键盘快捷键与浏览器冲突 | 用户体验 | 仅在画布 focus 时响应快捷键 |
